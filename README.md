# 假期安排 uTools 插件

用于按大小休周期计算月度休息日，并从官方安排中筛出真正增加的放假天数。

- 日历可切换每周从星期几开始，默认周日。
- 日历按上午、下午分别显示状态；两个时段相同时合并为全天。
- 放假、法定调休和法定补班作为日期标签；其中纯假期会参与实际休息结果，两个调班标签不参与。
- 右侧放假明细只列出日期，不标注上午、下午或全天；调休与补班记录显示在日历下方。
- 周六、周日可分别配置休息时段与重复间隔，默认使用大小休预设。
- 重复间隔 `0` 表示每周应用，`1` 表示隔 1 周应用一次；未轮到应用的周按上班处理。
- 双休、单休、大小休都是周六和周日规则的快捷预设，可继续手动调整。

## 计算口径

- `放假`：纯假期只按整天分配，不拆分为两个半天；优先取假期区间内原本全天上班的日期。
- `法定调休`：全天官方调休推荐显示日期标签，但不改变实际结果；只有一个工作半天被推荐调休时不显示标签，该半天未人工调休仍正常显示上班。
- `休息日重合`：完全按照大小休配置显示普通休息，不额外标记节日或重合状态。
- `法定补班`：只作为官方安排标签，不会直接记为实际补班。

点击日历日期即可打开统一的调班与修正窗口，并可切换调休、补班或修正。弹窗会根据当天最终结果选择默认操作：存在上班时段时默认调休，全天休息时默认补班。调休和补班记录以 `0.5` 天为最小单位。实际结果先按周末配置和官方纯假期计算；人工调休只累计仍为上班的时段，人工补班只累计已经休息的时段。人工记录会覆盖日历对应的上午或下午，最终显示为上班、休息、调休或补班。两者互相抵扣，负数余额显示为 `0`。

内置数据为 2026 年国务院办公厅公布的放假调休安排；法定日期按现行《全国年节及纪念日放假办法》拆分。进入本地尚无数据的年份时，插件会从 `NateScarlet/holiday-cn` 自动获取并保存；获取失败不会覆盖已有数据。其他年份也可在日历中逐日维护，或通过 JSON 导入。

## 本地运行

浏览器预览时，在当前目录启动任意静态服务器：

```bash
python3 -m http.server 4173
```

## uTools 载入

1. 打开 uTools 开发者工具。
2. 新建项目并选择本目录的 `plugin.json`。
3. 进入“假期安排”功能。

设置与节假日数据优先保存在 `utools.dbStorage`，普通浏览器预览时回退到 `localStorage`。首次获取新年份数据时需要联网。

数据保存和 JSON 导出使用同一种结构：节假日区间只保存一份元数据，零散日期保存在 `holidayData.days`；若区间中的某天被修正或删除，会用区间的 `dates` 列表保留其余日期。加载时恢复为按日期索引的日历数据。当前格式不兼容旧版存储或导出文件；启动新版本时旧版存储键会清理，旧版文件不能导入。

## 构建离线安装包

不要直接选择包含 `.git` 的项目根目录。先生成干净的打包目录：

```bash
npm run build:offline
```

然后在 uTools 开发者工具中选择 `dist/holiday-planner-utools` 目录构建离线安装包。该目录只包含插件运行所需文件，不包含 Git、测试或开发配置。

如果在 Windows 版 uTools 中开发 WSL 项目，不要直接选择 `\\wsl.localhost\...` 目录打包。请先把上述目录复制到 Windows 本机路径，再从本机目录重新载入 `plugin.json` 并构建离线安装包，避免打包器漏掉运行文件。
